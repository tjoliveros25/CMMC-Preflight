    The problem

    Companies that handle sensitive defense information have to protect it to a federal standard. Proving it costs more than many small shops make on the contract.

    $593,800 SBA's estimate of total compliance cost per certification for a small firm
    120,000+ Small businesses in the defense industrial base facing the requirement
    ~100 Approved assessors available to serve all of them

    The Department of War suspended the third-party certification phase in July 2026, citing exactly this cost. The requirements themselves did not go away: DFARS 252.204-7012 still applies, self-assessments are still required, and primes still push the obligations down to their subcontractors. A separate DoD cost model puts the assessment alone at $101,752 for a small entity, while a PreVeil survey found 3 in 5 contractors had budgeted under $50,000. Sources are listed at the bottom of this page.

    How it works

    1. 1

      Export your plan

      Two commands in your Terraform folder produce a plan.json describing your AWS setup.

      terraform plan -out=tfplan
terraform show -json tfplan > plan.json
    2. 2

      Drop it in

      The file is read by code running in your own browser. It is never uploaded, there is no server to send it to, and the site is served with a header that forbids the page from making outbound connections. Open your browser's network tab and watch.

    3. 3

      Read the report

      Every finding names the resource, says why it matters in one sentence, cites the NIST requirement, and gives you Terraform you can paste. Copy it, print it, or save it as a PDF for your file.

    What it is, and what it is not

    What it does

    • Reads a real Terraform plan, including resources inside modules
    • Checks 10 technical settings and maps each to a NIST SP 800-171 Rev 2 requirement
    • Explains each finding in plain English, with a fix you can paste
    • Says "could not determine" rather than guessing when the plan does not settle a value
    • Runs entirely in your browser, so the file never leaves your machine

    What it does not do

    • It is not a certification and does not replace a real assessment
    • It covers 10 of 110 requirements, all technical. Policy, training and physical security are not here
    • It reads what the plan says will be built, not what is running in your account today
    • It produces no SPRS score, and a pass does not mean a requirement is met
    • It needs Terraform, which the smallest shops may not use

    Free scanners for Terraform already exist and carry hundreds of rules. They are written for engineers. CMMC Preflight is written for the person who has to fill in the self-assessment.

        Why it cannot send your plan anywhere

        There is no server

        The whole tool is static files. No backend, no database, no account, nothing to receive a file even if the page tried to send one.

        The file is read locally

        Your plan is handed to the page by the browser's own file picker and read with the File API. It stays in memory on your machine and is dropped when you close the tab.

        A policy blocks the rest

        The site is served with a Content Security Policy that sets connect-src 'none', so the browser refuses any outbound request the page attempts.

        Nothing is stored

        No cookies, and the only thing kept in browser storage is which colour theme you chose.

        The policy, as served

        From vercel.json in the repository, applied to every response.

        Content-Security-Policy:
  default-src 'none';
  script-src 'self';
  style-src 'self';
  img-src 'self' data:;
  connect-src 'none';
  base-uri 'none';
  form-action 'none';
  frame-ancestors 'none'

X-Content-Type-Options: nosniff
Referrer-Policy: no-referrer

        connect-src 'none' is the line that matters: it forbids fetch, XMLHttpRequest and WebSocket entirely. form-action 'none' stops a form posting anywhere, and frame-ancestors 'none' stops another site embedding this one to read what you do. Check the headers yourself in your browser's network tab, or with curl -I against the deployed URL.

        What this does not protect against

        • A compromised browser or a malicious extension, which can read any page you open
        • A tampered copy of this site hosted by someone else. Check the URL and the source
        • Your own copy of the plan file, which still sits on your disk and may contain secrets
        • Anything you paste elsewhere afterwards, including into other AI tools

        The plan file is worth treating carefully in its own right. Terraform can write variable values into it, so keep it out of version control. The repository's .gitignore already blocks plan.json and tfplan for that reason.
